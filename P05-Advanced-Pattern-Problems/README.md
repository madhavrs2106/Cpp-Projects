# 🌟 Advanced Pattern Generator in C++

A menu-driven C++ application that generates various advanced star (`*`) patterns using object-oriented programming concepts. This project is ideal for beginners who want to strengthen their understanding of loops, nested loops, functions, classes, and pattern programming in C++.

---

## 📌 Features

- ✅ Menu-driven interface
- ✅ Object-Oriented Programming (Static Class Methods)
- ✅ Clean and modular code
- ✅ Easy to extend with new patterns
- ✅ Beginner-friendly implementation

---

## 🎨 Available Patterns

| No. | Pattern |
|-----|----------------------|

| 2 | Solid Diamond |
| 3 | Solid Butterfly |
